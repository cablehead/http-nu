# v0.19.0

## Highlights

### Errors as JSON on stdout

With `--log-format jsonl`, errors are logged to stdout as JSON, one line each, beside the request and response lines. Before, they went to stderr as plain text. With a handler that fails, saved as `log.jsonl`:

```nushell
open --raw log.jsonl | lines | each { from json } | where message == "error" | first | get error
```

```
Error:   x no such page
   ,-[source:1:19]
 1 | {|req| error make {msg: "no such page"}}
   :                   ^^^^^^^^^^^^^^^^^^^^^
   `----
```

`eval` and invalid command-line flags still print to stderr.

### cross-stream 0.16.0

The store behind `--store` is now xs 0.16.0. The [xs 0.16.0 release notes](https://github.com/cablehead/xs/releases/tag/v0.16.0) have the details.

- Topics kept to `last:n` frames stay fast as they grow: each append reads one index entry, where 0.14 read `n`.
- `POST /append-batch` appends many frames in one request, by [kiil](https://github.com/kiil).
- Content in the store's CAS is deleted once it is an hour old, unless a frame in the stream still has its hash. This happens when http-nu starts with `--store`, and when you `POST /gc` to the store's socket.
- Once this release has used a store, older http-nu releases must not open it again.

### Nushell 0.117.0

Handlers and actors run on Nushell 0.117.0. It removes `filter` (use `where`), the `-i` flag of `get`, `select` and `reject` (use `-o`), and `let-env`. Building from source needs Rust 1.97.1.

### Datastar 1.0.5

`--datastar` serves `/datastar@1.0.5.js`, and `--datastar-rocket` serves `/datastar-rocket@1.0.5.js`.

### Other changes

- Ctrl-C waits up to 10 seconds for requests to finish before stopping, the same as SIGTERM. Before, Ctrl-C cut them off (#63).
- An idle server uses no CPU. Before, it woke about 40 times a second (#62).
- Commands from `--plugin` plugins work in actors, services and actions. Before, only HTTP handlers could use them (#61).
