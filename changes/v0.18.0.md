# v0.18.0

## Highlights

- **xs store: 0.13.3 -> 0.14.1.** Several behavior changes can affect existing stores and scripts. See the xs [0.14.0](https://github.com/cablehead/xs/releases/tag/v0.14.0) and [0.14.1](https://github.com/cablehead/xs/releases/tag/v0.14.1) release notes for the full list.
  - Services now restart when their pipeline finishes cleanly (`restart: "on-success"` is the default). A one-shot service, such as a seed or migration step, now runs again every second unless it sets `restart: "never"`.
  - A following read (`.cat --follow`, `.last --follow`) now ends when it falls more than 4096 frames behind, instead of silently skipping frames. An SSE client sees its stream close and can reconnect from the last id it received.
  - `.id unpack` returns `ts_ms` (integer milliseconds) and `when` (a datetime) in place of `timestamp`. `.id`, `.id unpack` and `.id pack` are now three separate commands, so `.id unpack $id | get ts_ms` type-checks.
  - Frames with a `ttl: time:<ms>` are now deleted from disk when they expire, not just hidden from reads.

- **Streaming requests release their thread when the client disconnects.** Previously a handler streaming `to sse` from `.bus sub`, `.cat --follow` or `.last --follow` kept its thread until the stream next produced output, which on a quiet topic could be never. The thread is now freed once the client goes away. A stream that is not piped through `to sse` still holds its thread until it produces its first item.

- **Actors, services and actions can use `.mj`, `.md` and `.highlight`** (#48). These were only registered on the HTTP handler engine, so calling them from an [xs processor](https://cablehead.github.io/xs/reference/actors/) failed. The `$HTTP_NU` const, `-I` lib dirs and `--plugin` commands are not yet available there.

- **Nushell engine: 0.113.1 -> 0.116.0.** Scripts may need small edits:
  - `str downcase` / `str upcase` are deprecated in favor of `str lowercase` / `str uppercase`, and `get -i` / `reject -i` / `select -i` in favor of `-o`.
  - A custom command's declared output type is now enforced when it runs. A command declared `record -> record` that returns `null` errors; declare `oneof<record, nothing>` instead.
  - Type checking at parse time is stricter, so an annotation that used to pass may now be rejected.
  - Importing a module no longer implicitly imports its exported submodules; add `export use sub` to keep the old behavior.
  - `from yaml` now defaults to YAML 1.2.
  - New `from kdl` / `to kdl`.
  - Minimum Rust is now 1.96.1.

- **Datastar SDK: 1.0.2 -> 1.0.4.** The bundle http-nu serves under `--datastar` advances to `/datastar@1.0.4.js`. Upstream changes:
  - an opt-in [CSP mode](https://data-star.dev/reference/security#csp-mode) that runs without `unsafe-eval`, with support for aliased nonce attributes;
  - a new `@query()` action that sends `QUERY` requests with signals in the request body;
  - the current signals are sent when retrying a request after a network error;
  - fixes for request-cancellation races, reactivity after deleting a key from an object-shaped signal, signal patches when truncating arrays, action calls inside string and template literals, and `data-bind` on a `<select>` that gains `multiple`.

- **SIGTERM runs the xs shutdown protocol** (#53). With `--store`, `xs.stopping` now runs on SIGTERM as well as Ctrl-C, so services get to stop cleanly under process managers and containers.

- **The access log fits the terminal width**, down to a minimum of 96 columns, so wide terminals show more of each path. Paths are now shortened by character rather than byte, which fixes a crash that stopped the access log when a long path contained multi-byte characters.

- **An inherited `XS_APPEND_META` is no longer stamped on appended frames.** When http-nu was started from inside an xs service, that service's identity leaked into frames http-nu appended.

- **New example: [markdown-mermaid](https://github.com/cablehead/http-nu/tree/f5e7234/examples/markdown-mermaid)**, which renders mermaid diagrams inside markdown documents.
