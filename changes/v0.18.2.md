# v0.18.2

## Highlights

`.reverse-proxy` can now target a UNIX domain socket with `unix:<path>`, forwarding to an HTTP/1 server on a socket file instead of a TCP port. This works anywhere http-nu can already serve on a socket, Windows included. For socket targets, `preserve_host: false` sends `Host: localhost`, and a server listening on a socket now deletes the socket file when it stops so a stopped server no longer looks like it is still running.

The docs page gained a contents nav, and the getting-started guide's live-updates walkthrough and static-file serving were fixed up.
