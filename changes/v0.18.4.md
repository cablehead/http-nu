# v0.18.4

## Highlights

`--datastar-rocket` serves the Datastar bundle that includes [Rocket](https://data-star.dev/reference/rocket), Datastar's web-component API, at `/datastar-rocket@1.0.4.js`, in place of the core bundle `--datastar` serves. The two flags are mutually exclusive: the Rocket bundle carries all of Datastar, and a page that loads both runs two copies over the same DOM. `eval` takes the flag too, and `$HTTP_NU.datastar_rocket` reports it.

`SCRIPT-DATASTAR-ROCKET` in `http-nu/datastar` loads the bundle after an import map that names it `datastar`, so a component shipped as its own module can `import { rocket } from "datastar"` and share the page's copy without knowing where the page serves it. ptyZZZ's `<pty-term>` is the first such component. `$DATASTAR_ROCKET_JS_PATH` and `$DATASTAR_ROCKET_CDN_URL` sit beside the core constants.
